# Isaac Gym hard-room navigation evaluation

This evaluation reuses the original Isaac Gym `hard_room` height-field
generator. It does not create a second box-obstacle simulator and does not
modify either policy checkpoint. The room, obstacle height field, start point,
goal point, and initial yaw are generated by the existing environment code.

## Environment

Use the Isaac Gym environment that contains Preview 4 and the repository's
`sea_nav`/`legged_gym` packages. The HIMLoco policy remains the 270-input,
12-output low-level actor. The navigation actor remains the 550-input,
3-output SEA-Nav policy.

The deployment baseline is not changed. Work on:

```text
feature/isaacgym-rough-obstacle-navigation
```

## Viewer smoke sequence

Run the HIMLoco standing test first:

```bash
cd /home/hyz/桌面/sea_nav
conda activate sea_nav

python training/legged_gym/legged_gym/tests/test_env.py \
  --task go2_pos_rough \
  --locomotion_backend himloco \
  --himloco_policy models/locomotion/himloco/policy_1.pt \
  --viewer \
  --smoke_steps 2000 \
  --smoke_command 0 0 0
```

Then run SEA-Nav plus HIMLoco in one hard-room environment:

```bash
python training/legged_gym/legged_gym/scripts/play.py \
  --task go2_pos_rough \
  --navigation_checkpoint artifacts/go2_onboard/sea_nav_policy_2000.pt \
  --locomotion_backend himloco \
  --himloco_policy models/locomotion/himloco/policy_1.pt \
  --num_envs 1 \
  --seed 0 \
  --viewer \
  --navigation_speed_scale 1.0 \
  --eval_episodes 1 \
  --eval_steps 30000 \
  --eval_log /tmp/isaacgym_hard_room_seed0.jsonl
```

The navigation checkpoint path is a command-line argument. Replace it with
the actual local checkpoint path when the checkpoint is stored elsewhere.

## Headless multi-environment evaluation

```bash
python training/legged_gym/legged_gym/scripts/play.py \
  --task go2_pos_rough \
  --navigation_checkpoint artifacts/go2_onboard/sea_nav_policy_2000.pt \
  --locomotion_backend himloco \
  --himloco_policy models/locomotion/himloco/policy_1.pt \
  --num_envs 64 \
  --seed 0 \
  --headless \
  --navigation_speed_scale 1.0 \
  --eval_episodes 100 \
  --eval_steps 30000 \
  --eval_log logs/isaacgym_hard_room_seed0.jsonl
```

Use a different seed for a second independent layout:

```bash
--seed 1 --eval_log logs/isaacgym_hard_room_seed1.jsonl
```

## JSONL metrics

The evaluator writes a `step` record at the configured interval and an
`episode` record before stopping. Episode records include:

- seed, environment index, terrain name;
- random start XY and yaw;
- target XY;
- goal reached, collision, and fallen flags;
- path length and simulated time;
- minimum ray distance;
- maximum roll/pitch proxies from projected gravity;
- raw navigation command, filtered command, and HIMLoco action in step records;
- simulation control frequency and measured wall-clock loop frequency.

The environment's automatic reset is preserved. Episode fields are captured
before reset so a collision or fall is not lost from the log.

## Required debug order

1. HIMLoco zero command.
2. HIMLoco fixed forward command.
3. SEA-Nav hard-room viewer with one environment.
4. Same seed twice; compare start and target records.
5. Random yaw across seeds.
6. Random start and goal across seeds.
7. Headless multi-environment statistics.
8. Compare the same seed with the MuJoCo compatibility run.
9. Only after this baseline succeeds, add a separate continuous rough-ground experiment.

The first Isaac Gym baseline is intentionally the original `hard_room`. It is
not a stairs experiment and does not imply that SEA-Nav has been trained for
stairs or other non-flat terrain.
